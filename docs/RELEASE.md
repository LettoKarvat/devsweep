# DevSweep 0.2.0 - 27/10/2026

- Exportação JSON pela interface, preservando a exportação CSV.
- Relatório com data de geração em UTC, versões, raízes das candidatas, restrições e contadores da busca.
- Identificação de buscas interrompidas no JSON.
- Formato compartilhado entre a interface e a saída JSON do terminal, preservando os campos anteriores.
- Testes de exportação e regressão do CSV.

Relatórios continuam informativos; não podem ser importados para autorizar limpeza. A implementação desta atualização recebeu assistência de IA.

# DevSweep 0.1.0 - 20/10/2026

Primeira versão do DevSweep para Windows 10/11.

- Inventário de node_modules, ambientes virtuais Python e caches.
- Busca por pasta ou discos locais, com filtros por idade e tamanho.
- Seleção manual, revalidação e envio à Lixeira.
- Exportação CSV e inventário somente leitura pelo terminal.
- Proteções de escopo, instalações conhecidas e links/junções.

A idade representa alterações observadas, não o último uso do projeto. Nesta versão, candidatas com links/junções ficam somente no inventário.
