Primeira versão do DevSweep para Windows 10/11.

- Inventário de node_modules, ambientes virtuais Python e caches.
- Busca por pasta ou discos locais, com filtros por idade e tamanho.
- Seleção manual, revalidação e envio à Lixeira.
- Exportação CSV e inventário somente leitura pelo terminal.
- Proteções de escopo, instalações conhecidas e links/junções.

A idade representa alterações observadas, não o último uso do projeto. Nesta versão, candidatas com links/junções ficam somente no inventário.
